# The server on the 6.0.0 auth chain — implementation plan

> **For agentic workers: REQUIRED SUB-SKILL: superpowers:subagent-driven-development**

**Goal.** `mcp-abap-adt` stands on the published auth chain (auth-broker 5, auth-providers 6,
auth-stores 4, connection 15, interfaces-auth 7.5, auth-errors 2.2), split by transport into
`@mcp-abap-adt/core` (stdio), the new `@mcp-abap-adt/http` (Streamable HTTP, header credentials
only) and `@mcp-abap-adt/lib` (tools, embeddable server, no broker, no stores), SSE removed, and
every package released as 18.0.0 from PR #287 — with each request's cancellation reaching every
wait and every send, and every chain failure reaching the MCP client in the chain's own facts and
words.

**Architecture.** lib keeps the tools and a `ConnectionSource` contract each package fills: core
fills it from its default destination through one `AuthBroker`, http from the request's `x-sap-*`
headers, the embedder with its injected connection. A per-request `AbortSignal` lives in lib's
request signal scope; `createAdtClient` hands adt-clients a function reading it at each send, and
connection 15 honours it at every send boundary — releases run outside it. Failures are read once,
structurally, through auth-errors (`failureOf`), and end the tool call before any handler converts
them.

**Spec.** [`docs/superpowers/specs/2026-10-09-auth-chain-6-design.md`](../specs/2026-10-09-auth-chain-6-design.md)
(approved 2026-10-10, §18), answering the goal
[`docs/superpowers/2026-10-09-auth-chain-6-goal.md`](../2026-10-09-auth-chain-6-goal.md).

## Global Constraints

- Six packages at **18.0.0**, from PR #287, one major (D29).
- Packages: `@mcp-abap-adt/lib` (`.`), `@mcp-abap-adt/core` (`server/`, bin `mcp-abap-adt`, **stdio only**), `@mcp-abap-adt/http` (`http/`, bin `mcp-abap-adt-http`, **Streamable HTTP only**), `@mcp-abap-adt/compact-readonly`, `compact-modify`, `@mcp-abap-adt/compact` (bins `mcp-abap-adt-compact`, `mcp-abap-adt-compact-http`) (D35, D37).
- lib and http reach no `@mcp-abap-adt/auth-broker` or `@mcp-abap-adt/auth-stores`; core is the only package whose graph reaches them (D38).
- 18.0.0 ranges: auth-broker `^5.1.0` (core), auth-stores `^4.0.0` (core), auth-providers `^6.0.1`, connection `^15.0.0`, interfaces-adt-connection `^2.1.0`, interfaces-auth `^7.5.0`, auth-errors `^2.2.0`, interfaces-auth-broker `^1.3.0`, interfaces-auth-sap `^3.3.0`; interfaces-adt and adt-clients: the prerequisite releases of B3 and B5 (§18: the next free minor — today 13.3.0 and 27.1.0) (D1).
- One copy of `interfaces-auth` 7 and of `auth-errors` 2 resolves (`npm ls`).
- Registry only: every range resolves on npm; a prerequisite is published before anything builds against it; no `file:`, `link:`, `workspace:`; the lockfile holds no `"link": true` and nothing not from the registry (H7).
- The HTTP package takes credentials **only** from `x-sap-url`, `x-sap-client`, and `x-sap-jwt-token` or `x-sap-login` + `x-sap-password`; nothing stored, shared or cached across requests (D39).
- HTTP `400` without credentials, verbatim: "this server takes credentials only from the request's headers: send x-sap-url with x-sap-jwt-token, or with x-sap-login and x-sap-password".
- HTTP `400` on `x-mcp-destination`, verbatim: "destinations are served only by mcp-abap-adt (stdio); send x-sap-* headers".
- `--transport` is removed entirely; any value stops the start with the binary's D39 sentence (§10.1).
- `--login-timeout=<seconds>` (`MCP_LOGIN_TIMEOUT`, YAML `login-timeout`), whole number 1 to 86 400, **no default**; fired → "The login was ended by the server's login timeout (`--login-timeout=<n>`)" (D10).
- `--shutdown-timeout=<seconds>` (`MCP_SHUTDOWN_TIMEOUT`, YAML `shutdown-timeout`), **no default**; no shutdown deadline, no drain timer (D33).
- `--renewal=refresh-then-login|refresh-only` (`MCP_RENEWAL`, YAML `renewal`), default `refreshThenLogin()`; under `refresh-only`: "Logins are off (`--renewal=refresh-only`): log in with `mcp-auth`, or start without it." (D11).
- `onWriteFailure`: `'continue'` for a named destination (with or without `--unsafe`), `'fail'` for the `--env` / `--env-path` file; no `--session-write-failure` (D12).
- `--auth-debug` (YAML `auth-debug`), **no environment form**, core only (D24).
- `--browser` enum `system` (default) / `auto` / `chrome` / `edge` / `firefox` / `none` / `headless`, mapped by `process.platform` per §8; `--browser-program` excludes `--browser`; `--browser-auth-port` default **61001** (D9).
- The aborted request's code is connection's `ADT_REQUEST_ERROR.ABORTED` = `'ADT_REQUEST_ABORTED'`, answered `request_aborted` in fixed words (D34).
- A tool failure is JSON `{ error, kind, message, hint, server? }`: chain failure → `authentication_failed`; `DestinationConfigError` → `destination_refused`; aborted → `request_aborted`; own refusals `destination_refused` / `fresh_connection_unavailable` / `inspection_only` / `credentials_required` (§7.3).
- Out of every answer: `diagnostics` (stderr only), `facts` beyond `kind`, a thrown value's `message`, a token, a URL with a query, `state` (§7.3).
- A `403` with an ADT exception body is an ADT error, never `authentication_failed` (D47).
- `failureOf` reads no `message`, no `name`, uses no `instanceof` on a chain class (D14).
- No regular expression over untrusted input in the touched files (D26, H8).
- Nothing new on stdout; prompts on stderr (§9).
- Releases (unlocks, closes) are sent outside the request's signal (D40).
- No built-in timeout of the server's or the chain's making (H5).
- `freshConnection?: (options: { signal?: AbortSignal }) => Promise<IAbapConnection>`; without it the operation is refused: "This operation needs an ABAP session of its own; the connection was given by the host, which supplied no fresh-connection factory (`freshConnection`)" (D20).
- Publish order: `.`, `./compact-readonly`, `./compact-modify`, `./server`, `./http`, `./compact`; the publish is the user's (§11, §13).
- Tests: never `npx jest`; `npm test -- <path>` (root), `npm --prefix server test -- <path>`, `npm --prefix http test -- <path>`; a break is restored by copying the saved file back — never `git checkout`.
- Work only in `/home/okyslytsia/prj/mcp-abap-adt/.worktrees/auth-chain-6` (server) and a worktree of each prerequisite repository; the main checkouts are shared.

## How every task runs

- **Where.** Server tasks: `/home/okyslytsia/prj/mcp-abap-adt/.worktrees/auth-chain-6`, branch
  `feat/auth-chain-6`, PR fr0ster/mcp-abap-adt#287. A task never touches the main checkout or
  another worktree. Prerequisite tasks: a new worktree under that repository's `.worktrees/`.
- **TDD.** Write the failing test; run it and see it red **for the stated reason**; implement;
  run it green; then each load-bearing *break* the spec (or this plan) names: copy the file to the
  scratchpad, break it, run the test red, copy the saved file back, run green. Never `git checkout`
  to restore. Never `npx jest`.
- **Before a run.** `tests/test-config.yaml` must be absent in the worktree (it is today), so
  `npm test` runs unit suites only; any integration or live run is asked of the user first.
- **Gate before each commit.** `npm run lint:check`; `npm run build`; `npm run test:check`;
  `npm test`; `npm --prefix server run test:check`; `npm --prefix server test`; from A1 on also
  `npm --prefix http run test:check`; `npm --prefix http test`; from A7 on also
  `npm --prefix compact test`. A red gate is fixed, never skipped.
- **After each task.** Push the task's commits to the PR branch, then the task review (spec, then
  quality); findings go into the same PR. No background process is left running.
- **Docs.** Each task updates the documents its change makes stale and adds its rows to
  `docs/MIGRATION-18.0.md` (created in A2); C11 only checks the whole.
- **A prerequisite.** A task whose "Needs" names a release starts with `npm view <pkg>@<version>
  version dependencies`; not published → stop and report; the server never builds against it.

lib's `dependencies` where lib uses it, else root `devDependencies` — at **the same range** as the
`dependencies` of the package that publishes it. A task that moves a dependency (A3, A5, C1, C2,
