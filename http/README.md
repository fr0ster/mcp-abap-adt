# @mcp-abap-adt/http

The Streamable HTTP transport of the MCP ABAP ADT server: `StreamableHttpServer` serves the ADT
tools of [`@mcp-abap-adt/lib`](https://www.npmjs.com/package/@mcp-abap-adt/lib) over MCP Streamable
HTTP on an Express app, with DNS rebinding protection and optional TLS. The standalone server that
starts it is [`@mcp-abap-adt/core`](https://www.npmjs.com/package/@mcp-abap-adt/core). Licensed
AGPL-3.0-only.
